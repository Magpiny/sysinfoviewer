Easy Deployment

Installation Hub

Install SysInfoViewer via your preferred distribution package manager or run standalone anywhere.

Arch Linux / CachyOS / Manjaro (AUR)

SysInfoViewer is maintained on the Arch User Repository as sysinfoviewer. Install using your AUR helper: 

# Using paru
paru -S sysinfoviewer

# Or using yay
yay -S sysinfoviewer

Handles all dependencies, builds optimized native binaries, and sets up desktop entry automatically.

Standalone AppImage (Universal Linux)

Download the standalone executable and run it on any modern Linux distribution without installation: 

# Download the latest AppImage from GitHub Releases
wget https://github.com/Magpiny/sysinfoviewer/releases/download/v0.3.3/SysInfoViewer-0.3.3-x86_64.AppImage

# Make it executable and launch
chmod +x SysInfoViewer-0.3.3-x86_64.AppImage
./SysInfoViewer-0.3.3-x86_64.AppImage

Debian, Ubuntu & Linux Mint (.deb)

Download the official .deb package from the releases section and install via apt: 

# Download and install via apt
wget https://github.com/Magpiny/sysinfoviewer/releases/download/v0.3.3/sysinfoviewer-0.3.3-Linux.deb
sudo apt install ./sysinfoviewer-0.3.3-Linux.deb

Fedora, RHEL & openSUSE (.rpm)

Install the official RPM package natively via dnf or rpm: 

# Download and install via dnf
wget https://github.com/Magpiny/sysinfoviewer/releases/download/v0.3.3/sysinfoviewer-0.3.3-Linux.rpm
sudo dnf install ./sysinfoviewer-0.3.3-Linux.rpm

Build from Source

Compile from source with CMake and GCC 14+ / Clang 18+ (requires C++23): 

# 1. Clone repository
git clone https://github.com/Magpiny/sysinfoviewer.git
cd sysinfoviewer

# 2. Build with CMake
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)

# 3. Install system-wide
sudo cmake --install build

Technical Documentation

1. System Information Page

The System Information page comprises two rows. The top row hosts three synchronized real-time charts: CPU Usage (light pink & sky blue doughnut chart), Memory Allocation (brown & green doughnut with central GB breakdown), and Disk Usage (light pink & lavender proportional pie chart).

All three charts are scaled uniformly using radius = std::min(width, height) * 0.4 and centered at (width / 2.0, height / 2.0). On resize events, the Disk Usage text automatically switches across single-row horizontal, wrapped two-row, or stacked vertical configurations to eliminate label clipping.

2. Process Telemetry & Interactive Search

The Processes tab scans the kernel's /proc/[pid]/ directories asynchronously. It parses /proc/[pid]/stat for CPU tick calculations and /proc/[pid]/status for resident set size (VmRSS) memory usage.

Running processes are mapped to their respective desktop icon themes, and an instant search filter enables sub-millisecond filtering by process name, PID, or executing user.

3. UPower-Grade Battery Engine

The battery monitoring subsystem reads hardware registers via sysfs at /sys/class/power_supply/BAT*, retrieving energy_now, energy_full, power_now, and voltage_now (converted µWh → Wh and µW → W).

It integrates with the system upower service to fetch vendor, model, and serial metadata that sysfs does not expose, degrading gracefully to "Unknown" if UPower is not present.

4. Storage & Physical Block Device Resolution

SysInfoViewer queries /proc/mounts and follows sysfs symlinks under /sys/class/block/ to identify the physical parent disk drive (e.g. nvme0n1 or sda) backing mounted partition slices (such as /dev/nvme0n1p2).

This ensures disk capacity represents the entire physical device capacity in 512-byte sectors while tracking filesystem consumption via statvfs.

5. Display Hardware via Direct Rendering Manager (`libdrm`)

Unlike legacy tools relying solely on X11 extensions, SysInfoViewer inspects DRM connector status directly through the kernel Direct Rendering Manager (`libdrm`). This enables seamless multi-monitor detection, refresh rate querying, and EDID inspection across both Wayland (Sway, GNOME Wayland, Hyprland, KDE Plasma) and X11 sessions.
